# 海报模版字体清单

共 30 款，全部是 SIL Open Font License 1.1（可商用、可嵌入 App 和导出的图片、可随 App 分发；不能单独售卖字体文件；随 App 分发时附上许可文本）。

- `woff2/` 里是画布用的**子集**：GB2312 一级 3755 字 + 常见菜单字（如 焗、炖、咔嚓、莓）+ 模版里实际用到的字。改文案时基本不会缺字，但**App 端请打包完整字体**（从下表“来源”下载），否则生僻菜名会掉到系统字体。
- `fonts.css` 可以直接在网页 / WebView 里引用（`font-family` 名与模版 CSS 一致）。
- 完整字体中文字体单个 5–20 MB，建议按需下载：用户第一次选到某个模版时再下载它用到的字体并缓存。
